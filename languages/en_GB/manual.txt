<div style="text-align: center;"><b>IvaLineX - User Manual</b></div><br>
<b>Description:</b><br>
The application allows you to quickly count Python code lines in selected folders and projects. It supports saving results per project, tracking history, and displaying graphical progress of code, empty lines, and comments.<br><br>
<b>Main Features:</b><br>
- Select a project or folder with Python code<br>
- Count code lines, empty lines, and comments<br>
- Save results to project history<br>
- Visualize results in an interactive graph<br>
- Check required files for language versions<br>
- Application settings: language, default folder path, counting options (include __init__ files, empty lines, comments, .venv, README, JSON, etc.)<br>
- Option to reset settings<br>
- Clear menu with "About" and "Manual" options<br><br>
<b>Usage:</b><br>
1. Select a project or folder with Python code.<br>
2. Click the "Count Lines" button to start counting.<br>
3. If you want to save results to history, check "Save to History".<br>
4. Results will be displayed including number of files and total lines of code, empty lines, and comments.<br>
5. Project history allows you to track code evolution over time and shows it in a graphical chart.<br>
6. In the menu, you can open the manual or view information about the application.<br>
